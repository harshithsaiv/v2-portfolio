# 🚀 Modern Portfolio v2 - Software Engineer & AI/ML Specialist

> A high-performance, responsive portfolio showcasing expertise in Software Engineering, AI/ML, and GPU Computing through elegant design and smooth interactions.

![Portfolio Preview](public/preview.png)

## ✨ Key Features

- 🎨 Modern, minimalist design with dark theme optimized for tech professionals
- ⚡ Lightning-fast performance with React.js
- 🔄 Smooth page transitions and animations with Framer Motion
- 📱 Fully responsive across all devices
- 🛠️ Interactive project showcases highlighting AI/ML and GPU projects
- 📊 Real-time GitHub contribution stats
- 🎓 Dynamic education and certification timeline
- 💼 Detailed work experience with focus on software engineering and AI
- 🧠 Skills categorized by AI/ML, GPU Computing, Backend, and Cloud technologies
- 📚 Real-time "Now" page with current learning and projects

## 🛠️ Built With

- **Frontend**: React.js, Tailwind CSS
- **Animations**: Framer Motion
- **Routing**: React Router
- **Integrations**: GitHub API, Apple Music API
- **Deployment**: AWS, Vercel-ready
- **Design**: Modern, minimalist UI/UX

## 🚀 Quick Start

```bash
# Clone this repository
git clone https://github.com/yourusername/v2-portfolio

# Navigate to the project
cd v2-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to see your portfolio!
